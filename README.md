\# Text-Based Emotion Detection



A Django web application for text-based emotion classification using three approaches: Naive Bayes, LSTM, and fine-tuned RoBERTa.



\## Features

\- Predict emotions from user-provided text

\- Compare predictions from three models

\- Display six emotion categories: sadness, joy, love, anger, fear, and surprise

\- Web interface built with Django



\## Technologies

\- Python

\- Django

\- Scikit-learn

\- TensorFlow / Keras

\- PyTorch

\- Hugging Face Transformers
